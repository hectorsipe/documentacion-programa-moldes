Versiones y duplicados

Cuando el cliente pide cambios, no hace falta rehacer el presupuesto: crea una versión nueva y conserva el historial.

Crear una nueva versión

  1. Abre el presupuesto y entra en la pestaña Versiones.
  2. Pulsa Nueva versión, revisa el Nº de Versión propuesto (por ejemplo, 1.1) y escribe el Motivo nueva versión: «El cliente añade una segunda corredera».
  3. Pulsa Añadir. Se crea una copia con la misma referencia, su estimación y su ficha, que pasa a ser la versión actual.
  4. Modifica lo que haga falta y guarda.

En la tabla de versiones ves quién creó y modificó cada una, cuándo, el motivo (icono de información) y el importe. El icono del ojo abre una versión anterior para consultarla.

NotaSi abres una versión antigua, verás el aviso «Esta no es la última versión del presupuesto» y un enlace para ir a la última.

Duplicar un presupuesto

Para reutilizar un presupuesto parecido en otro trabajo o para otro cliente:

  1. Abre el presupuesto y, en la pestaña General, pulsa Duplicar Presupuesto.
  2. Marca Duplicar estimación de costes si quieres copiar también el desglose.
  3. Marca Mantener cliente o elige otro cliente con la lupa.
  4. Pulsa Duplicar. Se crea un presupuesto nuevo, con su propia referencia, en estado borrador.
