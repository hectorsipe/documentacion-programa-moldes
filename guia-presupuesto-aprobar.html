Aprobar y generar el proyecto

Cuando el cliente acepta la oferta, el presupuesto se convierte en proyecto con un solo botón, sin volver a escribir nada.

  1. Abre el presupuesto y, en Estado del presupuesto, cambia el estado a Aprobado. Si quieres, indica el motivo (por ejemplo, el número de pedido del cliente).
  2. Indica la Fecha Decisión y guarda.
  3. Pulsa Generar proyecto. Se crea el proyecto con el nombre, el cliente, el servicio, el importe presupuestado y la estimación.
  4. Abre el nuevo proyecto desde el bloque Proyecto del presupuesto (icono del ojo) o desde el listado de Proyectos, y revisa la fecha de inicio y la fecha de entrega prevista.
ImportanteUn presupuesto aprobado con proyecto ya no se puede modificar. Verás el aviso «Este presupuesto ya ha sido aprobado y tiene asignado un proyecto». Si el cliente pide cambios después, modifica el proyecto o crea un proyecto asociado.
NotaTambién puedes crear un proyecto sin presupuesto desde Proyectos › Añadir (por ejemplo, para pequeños mecanizados) y asignarle un presupuesto después con Asignar presupuesto.
